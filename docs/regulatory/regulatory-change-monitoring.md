## Monitoring cadence

- **Weekly:** scan for material regulatory notices affecting payment providers and pilot partners.
- **Monthly:** refresh legal-currentness register and source links.
- **Pre-release:** perform a mandatory delta assessment before new provider, country, payment, lending, custody or data-sharing features.
- **Post-event:** update the evidence register and change-control record.

## Change workflow

```text
New rule / notice
→ classify impact
→ identify affected product/contract/control
→ legal interpretation
→ technical impact assessment
→ implementation / compensating control
→ test evidence
→ partner communication
→ release gate update
→ archive source + decision
```

Never convert a regulatory web page or guidance note into a legal conclusion without counsel review where the issue affects TITech's authorization or liability.
