# Pilot Regulatory Control Checklist

Before each pilot is activated:

- [ ] Institution legal identity verified.
- [ ] Institution's regulated/licensed status checked where applicable.
- [ ] Regulated payment/custody partner identified.
- [ ] TITech custody boundary documented.
- [ ] Payment flow mapped end-to-end.
- [ ] Data controller/processor roles documented.
- [ ] Privacy notice approved by responsible institution.
- [ ] Consent/data-sharing purpose documented where consent is relied upon.
- [ ] KYC/AML responsibility matrix signed.
- [ ] Complaint/escalation ownership documented.
- [ ] Provider webhook authenticity controls validated.
- [ ] Reconciliation exception owner assigned.
- [ ] Maker-checker roles assigned.
- [ ] Incident contacts exchanged.
- [ ] Backup/restore responsibilities documented.
- [ ] Pilot acceptance criteria approved.
- [ ] Legal/regulatory open questions recorded.
- [ ] No marketing claim implies unauthorized regulated status.
