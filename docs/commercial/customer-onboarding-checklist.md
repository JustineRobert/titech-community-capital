# Customer Onboarding Checklist

- [ ] Legal entity and decision-maker verified.
- [ ] Contract and DPA/controller-processor terms agreed.
- [ ] Tenant provisioned.
- [ ] Roles/RBAC configured.
- [ ] CoA template approved.
- [ ] Provider configuration approved.
- [ ] Sample members imported.
- [ ] Golden Money Path test completed.
- [ ] Reconciliation test completed.
- [ ] Support contacts assigned.
- [ ] Backup/reporting expectations documented.
- [ ] Pilot baseline captured.
- [ ] Acceptance sign-off completed.
