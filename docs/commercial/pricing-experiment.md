# Pricing Experiment

These are experiments, not permanent price promises.

| Segment | Test price | Value hypothesis |
|---|---:|---|
| Small group | $10–25/month | Low-friction reconciliation SaaS |
| SACCO / Pro | $100–500/month | Institutional control + payment/reconciliation |
| Institutional | $500–2,500+/month | Multi-group/branch control, reporting and support |
| Enterprise | Custom | Scale, SLA, integrations, governance |
| Implementation | $1,000–10,000+ | Measurable deployment/change-management work |
| API/reconciliation | Usage based | Variable transaction/control value |
| Capital connectivity | Contract / partner based | Partner network and verified activity |

## Experiment rule

Price changes must be tied to observed willingness to pay, measurable ROI, implementation burden and retention.
