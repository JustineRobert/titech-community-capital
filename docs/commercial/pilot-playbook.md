# Pilot Playbook — Uganda Beachhead

## Funnel

```text
20 qualified candidates
→ 5 discovery conversations
→ 3 serious pilots
→ 1 immediate paid commitment
```

## Ideal institution

- 500–5,000 members;
- meaningful mobile-money/payment activity;
- visible reconciliation pain;
- manual reporting burden;
- accessible decision-maker;
- willingness to change workflow.

## Pilot value proposition

> TITech reduces contribution/payment reconciliation workload and provides a trusted institution-wide financial record.

## Pilot success metrics

- reconciliation time;
- unresolved exceptions;
- report preparation time;
- member onboarding time;
- payment failure rate;
- manual-entry count;
- support tickets;
- audit-preparation time;
- settlement visibility.

## Conversion condition

A pilot converts when the institution signs a commercial agreement and the measured value is credible enough to support renewal/continuation.
