# TITech Community Capital — Investor Metrics Evidence

The investor narrative should be built from verified operational data, not repository size.

## Adoption

- active institutions;
- active groups;
- active members;
- 30/60/90-day retention;
- onboarding completion time.

## Financial activity

- transaction count;
- transaction value;
- contribution volume;
- loan repayment volume where applicable;
- payment success rate;
- reconciliation success rate;
- unknown-payment rate.

## Reliability

- uptime;
- p95/p99 latency;
- idempotency duplicate-prevention rate;
- incident MTTR;
- failed-job recovery rate;
- backup/restore drill success.

## Commercial

- MRR / ARR;
- ARPU;
- contracted revenue;
- gross margin;
- CAC when enough data exists;
- net revenue retention when enough cohort data exists;
- pipeline by stage.

## Ecosystem

- verified payment rails;
- financial institution partners;
- capital-provider relationships;
- integration/API customers;
- funded cases or referrals where legally and operationally applicable.

### Evidence discipline

Mark each metric as one of:

`VERIFIED`, `PENDING`, `ESTIMATED`, `ASPIRATIONAL`.

Never present estimated or aspirational figures in the same visual treatment as verified production data.
