# Investor Evidence Room Index

## A — Company / strategy

- Product positioning
- 24-month allocation
- Africa expansion roadmap

## B — Product / engineering

- Critical path map
- Architecture decisions
- Production-readiness matrix
- Release gate reports

## C — Financial infrastructure

- Financial invariant specification
- Golden Money Path evidence
- Reconciliation evidence
- Provider certification evidence

## D — Security / privacy / regulatory

- Security assessments
- Data protection control package
- Regulatory boundary memo
- Legal review artifacts

## E — Customers / commercial

- Pilot acceptance records
- ROI case studies
- Contracts
- Invoices / payment evidence
- Renewal evidence

## F — Operations

- Deployment
- Rollback
- Backup/restore
- Incident response
- Support metrics

## G — Capital / partner network

- Bank/PSP contracts
- Capital-provider pipeline
- Ecosystem partner pipeline

**Evidence-room rule:** no investor material may cite a source artifact as “live customer proof” unless the corresponding external evidence artifact is present and independently reviewable.
