# Release Checklist

Before production approval verify:

- supported runtime and clean dependency install;
- startup/health/readiness/shutdown/restart;
- tenant isolation and RBAC;
- financial invariants and idempotency;
- Golden Money Path;
- callback security;
- reconciliation;
- security scans;
- backup/restore;
- deployment/rollback;
- provider certification;
- pilot/customer sign-off;
- legal/regulatory responsibilities;
- accountable production approval.

Use `reports/production-readiness.json` as the machine-readable summary.
