# Incident Response

Critical incident categories:

- ledger discrepancy;
- duplicate payment;
- stuck payment;
- provider outage;
- credential compromise;
- tenant-isolation breach;
- database/Redis outage;
- reconciliation backlog.

Every incident should record severity, commander/owner, correlation IDs, financial impact assessment, containment, recovery, customer communication, evidence preservation and post-incident review.
