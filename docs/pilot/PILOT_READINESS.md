# TITech Community Capital — Pilot Readiness

## Target pilot

Approximately 3–5 institutions, 50+ groups and 1,000–5,000 members without architectural redesign.

## Golden-path pilot acceptance

- Institution can onboard and configure operators.
- Groups and members can be managed.
- Financial activity can be recorded.
- Payment intent/execution can be traced.
- Ledger state remains controlled.
- Settlement and reconciliation can be explained.
- Receipts/reporting are available.
- Audit evidence is reconstructable.
- Exceptions can be assigned, reviewed and closed.
- Consent-controlled capital connectivity can be demonstrated without exposing unnecessary raw data.

## Evidence labels

Use only: `DESIGNED`, `IMPLEMENTED`, `TESTED`, `PILOT-READY`, `PRODUCTION-APPROVED`, `BLOCKED`.
