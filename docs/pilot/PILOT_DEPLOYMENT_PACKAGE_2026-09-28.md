# Three-SACCO Pilot Deployment Package

## Per-institution checklist

1. Institution profile and approved pilot agreement.
2. Tenant provisioned and isolated.
3. Named administrator, finance officer and approver.
4. RBAC and maker-checker verification.
5. Sample member onboarding with KYC status recorded.
6. Financial configuration and transaction limits applied.
7. Controlled MTN/test payment completed.
8. Ledger posting and reconciliation completed.
9. Audit trail and report export demonstrated.
10. Support escalation and incident process rehearsed.
11. Daily close and exception-review procedure demonstrated.
12. Pilot metrics baseline recorded.

## Pilot progression

`Internal Test → Controlled Sandbox → Production Verification → Small Pilot Volume → Expanded Pilot Volume → Operational Scale`

## Pilot success metrics

- onboarded members
- active users
- transaction count and volume
- payment success/failure/pending rate
- reconciliation match rate
- unresolved financial exceptions
- support tickets and resolution time
- availability
- retention

## Safety

Pilot limits, roles, approval thresholds and emergency disablement remain configurable. Offline or queued transactions are never treated as financially final before server confirmation.
