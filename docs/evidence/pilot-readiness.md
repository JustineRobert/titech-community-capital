# Pilot Readiness — 2026-10-04

## Target

Three real Ugandan SACCOs/community financial institutions remain the first controlled commercial proof target.

## Required onboarding chain

Institution agreement → tenant provisioning → users/RBAC → member import → financial workflow → provider connection → test transaction → ledger → reconciliation → receipt → audit → support.

## Archive status

The repository contains onboarding, tenancy, RBAC, payment, ledger, reconciliation, reporting and operational surfaces. This archive does not contain independent proof that three real institutions have completed the chain.

**Pilot status: UNPROVEN.**

No institution should be counted as a pilot solely because an MOU, sales conversation or source-level workflow exists.
