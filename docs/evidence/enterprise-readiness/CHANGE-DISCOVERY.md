## 1. How to locate the changed areas

Start from the repository root `titech-community-capital-main/`.

1. Open `TITECH_PLATFORM_TRUTH.md` for the current evidence index and release decision.
2. Open `docs/evidence/enterprise-readiness/FINAL-ENTERPRISE-READINESS-REPORT.md` for the complete execution verdict and gate results.
3. Open `backend/modules/audit/audit.service.js` for the shared audit-session correction.
4. Open `backend/modules/education/educationCampaign.service.js` for transaction-wrapped education-campaign mutations.
5. Open `backend/modules/edufinance/eduFinance.service.js` for atomic EduFinance submission and audit.
6. Open the three `*.transaction-contract.test.mjs` files under `backend/tests/unit/` to see the newly added executable source-contract tests.
7. Open `reports/` to inspect the static audit JSON artifacts generated by the 9 November gate runs.
8. Open `branding/TITECH_OFFICIAL_THEME.json` and `branding/TITECH_ORGANIZATION_PROFILE.json` to review the pre-existing official color and identity contracts. These files were verified, not rewritten.

## 3. Files deliberately not changed

- `branding/TITECH_OFFICIAL_THEME.json`, `branding/TITECH_ORGANIZATION_PROFILE.json`, brand CSS/JS tokens and the circular logo were not rewritten because the source already matches the requested identity and theme contract, and the official audit passed.
- Authentication, JWT, refresh-cookie, Redis, tenant, RBAC, payment, ledger, reconciliation and provider engines were not replaced or duplicated. Their existing code remains the canonical architecture; not all of their runtime behavior could be retested here.
- No historical records were bulk-renamed. Dated references to earlier legal/portal association names remain historical records, not current active identity.
- No unrelated modules, user records, financial records or production configuration were removed.
