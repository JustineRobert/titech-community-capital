# CI execution guide

Run on a machine meeting the repository runtime first: Node.js `24.15.0` and npm `>=11.0.0`. Install from the existing root/backend/frontend lockfiles using the repository's `npm run install:all` workflow; do not weaken engine checks. Provision isolated MongoDB replica-set test infrastructure and a dedicated Redis test namespace. Then run, in order: `npm run check:runtime`; `npm run audit:modules`; `npm run audit:test-discovery`; `npm run validate:syntax`; `npm run check`; `npm run test:backend:ci`; `npm run test:frontend:ci`; `npm run test:integration`; `npm run test:providers`; `npm run test:e2e`; `npm run test:coverage`; `npm run security:audit`; `npm run release:gate:strict`; `npm run production:approval-gate`. Record each exit code and retain generated reports. These commands are a repeatable next-step guide, not claims that those blocked commands passed in this environment.
