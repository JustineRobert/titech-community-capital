# Reconciliation Exception Runbook

1. Create/confirm exception ID.
2. Freeze automatic financial repair for ambiguous cases.
3. Collect provider event, internal event, transaction, journal and settlement references.
4. Compare amount, currency, account, status, timestamps.
5. Determine whether the issue is duplicate, missing, mismatch or timing.
6. Apply only an authorized compensating operation where appropriate.
7. Obtain maker-checker approval for privileged repair.
8. Re-run reconciliation.
9. Close exception with evidence and audit trail.
